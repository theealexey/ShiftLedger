# ShiftLedger

ShiftLedger — iPhone-приложение для людей с почасовой или сменной оплатой.

Пользователь фиксирует фактически отработанные смены и известные ему правила оплаты. Приложение независимо рассчитывает ожидаемую сумму начисления до налогов и удержаний, после чего позволяет сравнить её с фактическим начислением работодателя.

## Главная задача

Ответить на вопрос:

> Правильно ли мне начислили зарплату?

При этом ShiftLedger не просто показывает итоговую сумму, а должен объяснять, из каких часов, ставок и доплат она получилась.

## Первая версия

Планируется поддержка:

- одной работы;
- выбора валюты;
- фиксированной зоны времени работы;
- расчётных периодов по 7 дней, 14 дней или календарному месяцу;
- истории почасовых ставок;
- фактически отработанных смен;
- смен через полночь;
- одного неоплачиваемого перерыва;
- недельных сверхурочных;
- фиксированной ночной доплаты;
- повышенной оплаты выбранных дней недели;
- подробного расчёта начисления;
- сравнения ожидаемой суммы с начислением работодателя;
- истории расчётных периодов;
- локального хранения данных.

## Техническая основа

- Swift 6
- UIKit
- Core Data
- iOS 17+
- программная верстка интерфейса
- без Storyboard
- локальная работа без обязательного подключения к интернету

## Принцип проекта

> Ни одной необъяснимой суммы.

Расчёт должен быть детерминированным, проверяемым и покрытым тестами.

## Статус

Проект находится в активной разработке.

Текущий этап — первоначальная архитектура и первый вертикальный сценарий:

**создать работу → сохранить → перезапустить приложение → восстановить данные.**
